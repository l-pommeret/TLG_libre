# Lots de recherche manuelle

Ces fichiers sont des journaux de recherche par lots : ils ne modifient pas
automatiquement `canon_coverage.csv`. `proposed_status` est une proposition à
contrôler lors de l'intégration. Les OCR des fournisseurs ne sont jamais une
source de texte dans ces journaux.

`sources_tested` emploie `base-3` pour le contrôle négatif dans les checkout
locaux de Perseus, First1KGreek et PTA (recherche de l'URN TLG exact). Il ne
prétend pas que ces corpus ne contiennent jamais un témoin ou une citation de
l'oeuvre.
